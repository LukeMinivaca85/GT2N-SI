# GT2N-SI Pilot-Line Handoff

## Objective

GT2N-SI is a GT2N-derived experimental stacked-nanosheet GAAFET
process-development project.

The current package is predictive and is NOT fabrication-qualified.

## Requested pilot-line review

The fabrication partner should determine:

1. Which FEOL dimensions can be implemented.
2. Which dimensions require modification.
3. Whether three stacked nanosheets are practical.
4. Achievable gate stack / EOT.
5. Contact module capability.
6. Minimum practical metal pitch.
7. Via integration limitations.
8. Backside-power feasibility.
9. Required mask/process modifications.
10. Required characterization structures.

## Reference targets

- Gate length: 14 nm
- EOT: 0.7 nm
- Nanosheet thickness: 5 nm
- Width variants: 13 nm / 31 nm
- Three stacked channels
- M0 pitch: 24 nm
- M1 pitch: 28 nm
- BSPDN target

These are predictive design targets, not measured silicon.

## Expected fabrication output

- wafer or diced TV0 dies
- process-flow revision
- actual fabricated dimensions
- electrical measurements
- metrology data where available
- deviations from target process

## Calibration output

Measured data will be used to update:

- BSIM-CMG compact models
- interconnect RC
- via resistance
- parasitic extraction
- Liberty characterization
- DRC constraints
